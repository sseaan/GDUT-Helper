# 隐私说明

工大助手是本地优先应用，不提供在线账号，也不把个人数据上传到自建服务器。

## 本地保存

- 学期、课程、单周停课/调课、日程和考试；
- 成绩、体测成绩缓存；
- 课表显示、主题模式、主题色、沉浸光感强度、智感握姿、本地通知、提醒和系统日历开关；
- 用户选择的头像文件（仅保存在应用沙箱）。

## 安全存储

- 教务账号和密码保存在系统 Asset Store（`gdut_helper_jxfw_account`），仅设备首次解锁后可用；
- 体测账号密码使用独立存储；
- 密码、Cookie、Token、ticket、验证码不写入 RDB、Preferences、日志或备份文件。

## 联网访问

应用仅代表用户访问学校系统：

- `authserver.gdut.edu.cn`：统一认证；
- `jxfw.gdut.edu.cn`：课表、考试、成绩；
- `jwcwx.gdut.edu.cn`：空教室；
- `tzcs.gdut.edu.cn`：体测平台（WebView 登录）。

请求只用于完成用户主动触发的同步、查询和登录。

## 文件权限

- 导入/导出通过系统文件选择器完成，不申请宽泛存储权限；
- 只读取用户主动选择的文件；
- 备份不包含账号密码、会话凭据、系统日历映射和验证码；
- ICS 导出文件包含课程、考试和日程信息，由用户选择保存位置；导出后不再由应用管理；
- 导入失败不写入半成品数据，JSON 恢复失败会回滚业务表。

## 本地通知

- 本地通知通过系统 `notificationManager` 发布，不经过自建服务器；
- 通知内容仅包含课表同步状态等本地生成的信息；
- 通知权限由用户主动开启，可随时在功能设置中关闭；
- 精确时间代理提醒仍受签名权益限制，不在本地通知范围内。

## 数据删除

- 删除课程会删除对应单周调整；
- 应用卸载会删除沙箱内的 RDB、Preferences 和头像；
- 系统日历和提醒需要用户在系统设置或应用开关中清理。
