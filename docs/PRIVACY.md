# 隐私说明

工大助手是本地优先应用，不提供在线账号，也不把个人数据上传到自建服务器。

## 本地保存

- 学期、课程、单周停课/调课、日程和考试；
- 选课任务、抢课队列和运行日志（仅本地，最多保留 600 条日志）；
- 成绩、体测成绩缓存；
- 课表显示、主题模式、主题色、沉浸光感强度、智感握姿、本地通知、提醒和系统日历开关；
- 用户选择的头像文件（仅保存在应用沙箱）。

## 安全存储

- 教务账号和密码保存在系统 Asset Store（`gdut_helper_jxfw_account`），仅设备首次解锁后可用；
- 体测账号密码使用独立存储；
- 密码、Cookie、Token、ticket、验证码不写入 RDB、Preferences、日志或备份文件。

## 联网访问

应用仅代表用户访问学校系统：

- `authserver.gdut.edu.cn`：统一认证；
- `jxfw.gdut.edu.cn`：课表、考试、成绩、选课（查询与提交）；
- `jwcwx.gdut.edu.cn`：空教室；
- `tzcs.gdut.edu.cn`：体测平台（WebView 登录）；
- `opac.gdut.edu.cn`：图书馆公开目录（馆藏检索，不携带登录态）；
- `bd.bdfairy.cn`：电费查询（Beta，**电表服务商**站点，明文 HTTP）。

请求只用于完成用户主动触发的同步、查询和登录。

## 电费查询（Beta）

- 默认关闭，需在「功能设置」中阅读免责声明后主动开启；
- 请求只包含校区与电表表号，以明文 HTTP 发往电表服务商站点 `bd.bdfairy.cn`（电精灵）；
- 表号保存在本机 Preferences（避免每次重输），**余额只留在内存，不写入 RDB、日志或备份**；
- 功能仍处于 Beta，接口可能随时调整或中断，结果仅供参考，请以电表读数和缴费记录为准。

## 日历同步（CalDAV）

- 目标服务器由用户自己填写（Radicale、Nextcloud 等），应用不内置任何日历服务；
- 推送内容只有课程、考试和日程的标题、时间、地点、备注，不含账号、成绩或身份证类信息；
- 集合地址、用户名和开关保存在 Preferences，**密码只进系统 Asset Store**，不写日志、不进备份；
- 推送索引 `caldav_index.json` 只存在应用沙箱，记录已推送事件的 UID/文件名/指纹，用于增量与清理；
- 该功能是单向镜像：应用不会读取远端日历里的其它事件。

## 扫码

- 使用系统扫码器（Scan Kit 默认 UI），**不申请相机权限**，应用既不接触也不保存摄像头画面；
- 扫码结果只在本地分类处理：`http(s)` 链接交给系统浏览器，合法 ISBN 进入馆藏检索，
  其余文本弹出对话框由用户选择复制、浏览器搜索或取消；
- 扫码内容不写入 RDB、Preferences、日志和备份。

## 文件权限

- 导入/导出通过系统文件选择器完成，不申请宽泛存储权限；
- 只读取用户主动选择的文件；
- 备份包含选课任务和队列配置，但不包含账号密码、会话凭据、系统日历映射和验证码；
- ICS 导出文件包含课程、考试和日程信息，由用户选择保存位置；导出后不再由应用管理；
- 导入失败不写入半成品数据，JSON 恢复失败会回滚业务表。

## 本地通知

- 本地通知通过系统 `notificationManager` 发布，不经过自建服务器；
- 通知内容仅包含课表同步状态等本地生成的信息；
- 通知权限由用户主动开启，可随时在功能设置中关闭；
- 精确时间代理提醒仍受签名权益限制，不在本地通知范围内。

## 数据删除

- 删除课程会删除对应单周调整；
- 应用卸载会删除沙箱内的 RDB、Preferences 和头像；
- 系统日历和提醒需要用户在系统设置或应用开关中清理。
